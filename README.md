# Magyar — Telegram Mini App для підготовки до консульської співбесіди

Тренажер угорської під конкретну мету: усна співбесіда в консульстві на спрощену
натуралізацію. Не універсальний курс — усе підпорядковано темам співбесіди.

**Живі адреси:**
- Railway (основна): https://magyarok-production.up.railway.app
- GitHub Pages (резервна): https://kovtunvitalik58-ui.github.io/magyarok/

Railway підключений до цього репозиторію: кожен push у `main` передеплоює
застосунок автоматично.

## Методика

Застосунок побудований на п'яти механізмах, у порядку важливості:

**1. Retrieval practice (витягування з пам'яті).**
Жодна вправа не показує відповідь до того, як ти спробував її згадати. Пасивне
перечитування списків не працює — працює болісне пригадування.

**2. Spaced repetition (SM-2).**
Кожне слово має власний інтервал і коефіцієнт легкості. Провалив — інтервал
скидається і слово падає на щабель нижче. Це не гейміфікація, це графік забування.

**3. Сходи витягування.**
Слово не «вивчене» після одного правильного вибору з чотирьох. Воно проходить
чотири щаблі, і кожен вимагає більше:

| Щабель | Вправа | Що тренує |
|---|---|---|
| 0 | HU → UA, вибір | упізнавання |
| 1 | UA → HU, вибір | зворотне упізнавання |
| 2 | UA → HU, набір тексту | продукування форми |
| 3 | клоуз у реченні | продукування в контексті |

Щабель росте лише разом із правильними відповідями. Помилка відкидає на щабель назад.

**4. Interleaving (перемішування).**
Лексика, граматичні дрили, гармонія голосних і збірка речень ідуть упереміш, а не
блоками. Блокова практика дає ілюзію засвоєння; перемішана дає повільніший
прогрес у моменті й значно кращий результат на віддалі.

**5. Автогенеровані дрили на гармонію голосних.**
Гармонія обчислюється з самого слова (`js/harmony.js`), тому вправ на суфікси
нескінченно багато й вони не «вивчаються напам'ять». Для слов'янина це головна
механічна перешкода в угорській, і вона потребує сотень повторів, а не пояснення.

**Окремо: контроль довготи голосних.** При наборі тексту застосунок відрізняє
«не знаю слова» від «переплутав `a`/`á`» і в другому випадку дає прицільне
зауваження. Довгота в угорській розрізняє значення (`ver` б'є / `vér` кров), а
українське вухо її не чує — це найчастіша системна помилка.

## Структура

```
miniapp/
  index.html
  server.js     статичний сервер для Railway
  package.json
  css/style.css
  js/
    app.js        роутер, ініціалізація
    tg.js         Telegram WebApp + сховище (localStorage + CloudStorage)
    srs.js        планувальник SM-2 + сходи витягування
    harmony.js    обчислення гармонії голосних, генератор дрилів
    session.js    рушій заняття: збирає й рендерить змішану сесію
    screens.js    головна, граматика, консул, словник, профіль, план, прогрес
    anki.js       розділ «Анкі»: колоди, перегляд, режим навчання
  data/
    vocab.js      238 слів, розмічені за тижнем і темою
    grammar.js    11 граматичних модулів з поясненнями і дрилами
    interview.js  48 питань співбесіди + шаблони відповідей і поля профілю
    plan.js       39-тижневий план
    anki.js       колоди з CSV-файлів користувача
```

Жодних залежностей, збірки чи бекенду. Чистий ES-модульний JS.

## Екрани

- **Головна** — поточний тиждень плану, що було минулого тижня, кнопка «заняття дня».
- **Заняття** — змішана сесія: повторення + нові слова + граматика + гармонія +
  порядок слів + 3 питання співбесіди в кінці. ~15 хв.
- **Граматика** — 11 модулів з поясненнями через порівняння з українською.
  Кожен має власний дрил.
- **Консул** — симуляція співбесіди. Повний прогін на 10 питань або окремі блоки
  (родина, предки, мотивація, реалії). Рівень складності відкривається за тижнем плану.
- **Словник** — усі розблоковані слова, фільтр за темою, експорт у форматі Anki.
- **Анкі** — колоди з твоїх CSV-файлів. Класичний флеш-карт цикл із тим самим
  планувальником SM-2, що й у словнику, але прогрес зберігається окремо.
  До 20 нових карток за підхід.
- **Мій профіль** — твої персональні дані для зразків відповідей. Живуть лише
  на пристрої.
- **План** — усі 39 тижнів із позначкою поточного.
- **Прогрес** — графік за 14 днів, проблемні слова, журнал помилок з кнопкою
  «скопіювати для викладача».

## Перевірка перед деплоєм

```bash
node check.mjs
```

Перевіряє синтаксис і імпорти всіх модулів плюс цілісність даних: унікальність
id словника, існування правильної відповіді в кожному дрилі, відповідність
плейсхолдерів полям профілю, відсутність персональних даних.

Ганяти **обов'язково перед кожним push**. Синтаксична помилка в модулі
проявляється лише як вічний екран «Завантаження…» — в інтерфейсі жодного
повідомлення, тільки запис у консолі браузера. Очима таке не ловиться.

`hang-test.html` імітує клієнт Telegram, у якого CloudStorage не відповідає:
відкрий його й переконайся, що головна все одно з'являється за ~3 секунди.

## Локальний запуск

```bash
python -m http.server 8765 --directory miniapp
```

Відкрий `http://localhost:8765`. Працює і поза Telegram — усі виклики
Telegram API під feature detection.

## Розгортання на Railway

У теці вже є `server.js` (статичний сервер без залежностей) і `package.json`.
Railway сам визначить Node і запустить `npm start`; порт береться з `$PORT`.

```bash
railway login
```

Далі з теки `miniapp`:

```bash
railway init --name magyarok
```

```bash
railway up
```

```bash
railway domain
```

Остання команда видає публічну HTTPS-адресу виду `magyarok-production.up.railway.app`.
Наступні оновлення — просто `railway up` з тієї ж теки.

Перевірка, що все живе: `https://твоя-адреса/health` має віддати `ok`.

## Підключення до бота

1. У Telegram відкрий [@BotFather](https://t.me/BotFather) → `/newbot` → задай ім'я.
2. `/mybots` → обери бота → **Bot Settings → Menu Button → Configure menu button**.
3. Встав HTTPS-адресу з Railway і назву кнопки, наприклад `Magyar`.

Токен бота для цього не потрібен — усе робиться в чаті з BotFather.

Для окремого посилання виду `t.me/твій_бот/magyarok`: `/newapp` у BotFather,
обери бота, задай назву, короткий опис, іконку 640×360 і ту саму URL.

## Синхронізація прогресу

Прогрес зберігається в `localStorage`, а всередині Telegram (Bot API 6.9+)
дублюється в `CloudStorage` — тобто переживає перевстановлення й переїзд на інший
пристрій. Поза Telegram працює тільки localStorage.

## Як додавати матеріал

**Нові слова** — `data/vocab.js`:

```js
{id:239, hu:'…', ua:'…', ex:'…', exUa:'…', w:12, t:'csalad'},
```

`w` — з якого тижня слово розблоковується, `t` — ключ із `TOPICS`. `id` має бути
унікальним; прогрес прив'язаний саме до нього, тому не перенумеровуй існуючі.

**Граматичний модуль** — `data/grammar.js`. Поле `explain` розуміє спрощений
markdown: `**жирний**`, `*курсив*`, `` `код` `` і таблиці на трубах.

**Питання співбесіди** — `data/interview.js`. `lvl` 1–3 керує тим, з якого тижня
питання з'являється.

**Колода Anki** — `data/anki.js`. Вихідний CSV має дві колонки:

```
Jó napot kívánok!,[йоо напот кііваанок] — Доброго дня! (ввічливо)
ЛІТЕРА: s,Читається як «ш» (sok = [шок]).
```

Рядок із `[транскрипція] — переклад` стає карткою лексики, будь-який інший —
карткою правила (`kind:'rule'`): спереду підпис, ззаду пояснення, без транскрипції.

id карток мають префікс колоди (`u1-01`) і не повинні перетинатися з id словника —
`check.mjs` це перевіряє, бо прогрес прив'язаний саме до id.

## Персональні дані

У вихідному коді немає жодних реальних персональних даних. Зразки відповідей
у `data/interview.js` містять плейсхолдери — `{NÉV}`, `{ŐS}`, `{VÁROS}` тощо, —
які підставляються з профілю на екрані **«Мій профіль»**.

Профіль зберігається лише в `localStorage` пристрою і в твоєму приватному
Telegram CloudStorage. Він ніколи не потрапляє ні в репозиторій, ні на сервер
Railway: сервер віддає статичні файли й нічого не читає та не пише.

Заповни профіль до першої серйозної сесії — інакше вивчиш чужу біографію.
Це найважливіше з усього.

Питання №41 (президент і прем'єр-міністр) навмисне залишене без прізвищ:
їх треба перевірити безпосередньо перед співбесідою.
